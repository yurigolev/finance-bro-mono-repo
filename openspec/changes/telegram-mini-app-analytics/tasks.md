# Tasks

## 1. Каркас Mini App

- [x] 1.1 Создать отдельный Nuxt 4 клиент с TypeScript, shadcn-vue и Reka UI. Проверить typecheck и статическую сборку.
- [x] 1.2 Подключить Telegram WebApp, тему и безопасные отступы. Проверить смену темы без сброса состояния и понятный экран при открытии обычной ссылкой.

## 2. API аналитики

- [x] 2.1 Добавить проверку данных запуска и привязку к владельцу. Проверить действительную, отсутствующую, подменённую и просроченную подпись, включая запрос пользователя с чужим идентификатором.
- [x] 2.2 Собрать агрегаты по периодам из PostgreSQL и описать контракт API. Проверить доходы и расходы, границы дня и месяца, переходы летнего времени, UTC, удалённые операции, архивные категории, расходы без категории и пустые дни.
- [x] 2.3 Подключить HTTP-маршрут и защиту от кэширования. Проверить ответы для трёх периодов, коды 400 и 401 и отсутствие данных запуска в логах.

## 3. Экран аналитики

- [x] 3.1 Собрать переключатель периода и блок итогов, подключить API, обновление при возврате в Mini App и повтор загрузки. Проверить загрузку, пустой период, ошибку, истечение авторизации и быстрое переключение периодов.
- [x] 3.2 Добавить парный график Unovis, выбор дня и текстовую таблицу. Проверить тап и клавиатуру, месячный ряд на ширине 320 CSS px, читаемость обеих тем и размер производственной сборки.
- [x] 3.3 Добавить список категорий с долями. Проверить сортировку, длинные названия, «Без категории», большие суммы и периоды с одними доходами.

## 4. Интеграция с Telegram

- [ ] 4.1 Поднять тестовый HTTPS-вход для Mini App, настроить кнопку «Аналитика» на тестовом боте и описать включение и откат. Проверить запуск из меню на iOS и Android.
- [ ] 4.2 Пройти сценарий двумя аккаунтами. Записать доход и расход, сверить бота с Mini App за тот же период, удалить расход и убедиться, что после обновления он исчез из итогов, графика и категории. Проверить, что каждый аккаунт видит только свои операции.
