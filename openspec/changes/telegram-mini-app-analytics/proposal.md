# Proposal

## Why

Операции уже записываются в Telegram, но для обзора доходов и расходов по дням и категориям нужен мобильный экран. Mini App позволяет открыть обзор прямо из меню бота.

## What Changes

- Добавить кнопку «Аналитика» в меню личного чата с ботом.
- Спроектировать отдельный Mini App на Nuxt 4, Vue 3, TypeScript, shadcn-vue и Reka UI с оформлением по теме Telegram.
- Показать итоги, динамику по дням и расходы по категориям за текущий месяц, последние семь дней или прошлый месяц.
- Добавить API чтения агрегатов из существующего PostgreSQL с проверкой запуска через Telegram и привязкой к владельцу операций.
- Редактирование операций, детализация до отдельных записей, бюджеты и остатки по счетам вне первого релиза Mini App.

## Capabilities

### New Capabilities

- `telegram-mini-app-analytics` — открытие аналитики из Telegram и просмотр своих операций в агрегированном виде за выбранный период.

### Modified Capabilities

## Impact

- Новый клиент в `mini-app/`, существующий бот и сервис учёта в `backend/`.
- Планируются HTTP API, HTTPS-размещение и отдельная настройка кнопки для тестового бота.
- Источник данных — текущие таблицы PostgreSQL. Аналитику первого релиза можно собрать без миграции схемы.
