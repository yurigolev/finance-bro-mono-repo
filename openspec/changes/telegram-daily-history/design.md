# Design

## Context

Сейчас запрос истории ограничен десятью последними активными операциями. В таблице хранится время создания `created_at`. Кнопки категории и удаления уже адресуют запись по ID. [Дорожная карта](../../roadmap.md) предусматривает дату совершения и часовой пояс пользователя.

## Goals

- Один способ получить операции за выбранный день для открытия, навигации и обновления после действий.
- Доступ к ранее сохранённым операциям после перехода на дату совершения.

## Decisions

1. **Дата и часовой пояс.** Хранить время совершения в `occurred_at`. Для старых записей взять `created_at`, для обычного ввода одной строкой записывать текущее время. Границы локального дня вычислять по сохранённому часовому поясу IANA. Если пояс ещё не задан, использовать UTC и показывать его рядом с датой. Управление часовым поясом и ввод прошлой даты рассматриваются отдельно в дорожной карте.
2. **Запрос одного дня.** Запрашивать активные записи владельца за местную календарную дату. Сортировать по времени совершения и ID. Доходы и расходы суммировать отдельно по всем полученным записям в копейках. Группировать расходы и доходы, сохраняя порядок внутри каждого раздела. Ставить сумму со знаком слева и выводить категорию только при наличии.
3. **Навигация по сообщению.** В кнопке перехода передавать целевую календарную дату и при необходимости страницу или признак «сегодня». Обновлять текст и клавиатуру сообщения через Telegram. Строку навигации по дням показывать даже при пустом списке.
4. **Действия с операциями.** Использовать существующие проверки владельца и совместимости категории. После действия перечитать ту же дату, пересчитать обе суммы и вернуться на ту же или последнюю доступную страницу. Кнопки показывают сумму и описание, а запись адресуют по ID.

## Risks / Trade-offs

- Дни перевода часов могут длиться 23 или 25 часов. Ограничить поиск по индексу диапазоном UTC и проверять локальную дату каждой найденной записи, включая обе версии повторяющейся полуночи.
- Telegram ограничивает размер сообщения и клавиатуры. Вмещать максимум строк в пределах лимита текущего формата. В режиме выбора дополнительно учитывать предел клавиатуры. Номер страницы показывать только при наличии нескольких страниц.
- К моменту нажатия запись может исчезнуть из истории. Проверять её доступность при действии и сообщать об устаревшей кнопке.

## Migration Plan

Добавить и заполнить `occurred_at` до включения меню по дням. Проверить доступность записей, созданных до миграции. При откате бота оставить заполненную колонку в базе.
