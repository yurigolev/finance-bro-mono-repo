- [x] 1.1 Записать модель целевого iPhone и версию iOS; проверить поддержку WidgetKit Control и выбрать ветку Speech API по design.md. Результат — заполненная матрица совместимости в отчёте прототипа.
- [ ] 1.2 Установить полную Xcode с нужным iOS SDK, выбрать её active developer directory; проверить, что `xcodebuild -version` и список устройств Xcode работают.
- [ ] 1.3 Создать Xcode-проект с app target, Widget Extension, общим App Intent и test target; проверить сборку app scheme для симулятора и наличие Control в extension.
- [ ] 1.4 Настроить automatic signing обоих targets, подключить iPhone, подтвердить доверие и включить Developer Mode при запросе; проверить, что пустая тестовая сборка запускается на физическом устройстве, и записать срок действия подписи.
