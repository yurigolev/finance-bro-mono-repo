# Proposal

## Why

Разбор голоса и текста сейчас связан с Telegram-обработчиками, а запись операций и HTTP API Mini App запускаются в одном процессе с ботом. Отдельный обработчик нужен, чтобы другие авторизованные клиенты могли разбирать голос и текст через общий контракт, сохранив привычные сценарии Telegram.

## What Changes

- Разделить Telegram-бота, обработчик ввода и финансовое ядро на отдельные сервисы. Обработчик вызывает существующий Whisper только для аудио.
- Добавить версионированный HTTP API разбора, общий для бота и других клиентских бэкендов. Результат включает черновик, варианты категорий и поля для уточнения.
- Оставить экраны, Telegram API и диалоги боту. Ядро владеет PostgreSQL, хранит правила, обслуживает API Mini App и принимает команды финансовых операций.
- Провести миграцию по этапам. Сначала перенести текущие вызовы бота за HTTP с сохранением поведения, затем переключить запись на структурированный результат обработчика.

## Capabilities

### New Capabilities

- `transaction-input-processing` — разбор текста и аудио для независимых клиентов по одному контракту.
- `financial-operation-commands` — авторизованная запись разобранных операций и обновление категории с предсказуемым повтором.

## Impact

Затрагивает точки запуска backend, Telegram-адаптер, парсеры, правила сопоставления категорий, финансовые HTTP-обработчики, Compose и прокси Mini App. Проверки опираются на действующие сценарии записи, категорий, истории, бюджетов и Mini App. Подключение нового клиентского интерфейса выполняется отдельным изменением.
