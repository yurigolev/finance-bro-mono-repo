# Эталон перед разделением

Проверено на рабочей копии до изменения точек запуска, с отдельным PostgreSQL 18 и синтетическими Telegram-данными.

| Проверка | Результат |
| --- | --- |
| `npm --prefix backend test` с тестовым PostgreSQL | 62/62, без пропусков |
| `npm --prefix backend run db:migrate` и `npm --prefix backend run test:integration` | Миграции применились, 26/26 без пропусков |
| `npm --prefix mini-app run typecheck` и `npm --prefix mini-app run generate` | Проверки прошли, 8 статических маршрутов |
| Mini App в браузере через текущий HTTP API | Аналитика, сравнение, бюджеты, история, запись через форму, настройки и сброс часового пояса. Без подписанных данных Telegram защищённые маршруты возвращают 401. |

Бот с текстом и голосом «В прошлый вторник кофе в путешествии 400 ₽» сначала просит подтвердить 17.11.2026, затем показывает чек и кандидатов по правилам. Эталонный тест проверяет дату в PostgreSQL, выбор категории, удаление и повтор доставки. После его добавления набор бота прошёл 63/63.

Исходный парсер отклоняет форму `400р`. Поддержка этого написания требуется контрактом нового обработчика. Эталон основного сценария использует ранее поддерживаемую форму `400 ₽`.
