# Тестовый запуск Mini App

Используйте отдельного бота, отдельную PostgreSQL и тестовые аккаунты A и B. Укажите токен тестового бота в переменной `BOT_TOKEN` тестового бэкенда и в `TEST_TELEGRAM_BOT_TOKEN` для управления его меню. Передавайте токен через менеджер секретов или переменные процесса.

## HTTPS для Telegram

Запустите [профиль Compose `mini-app`](../../README.md#запуск-с-mini-app). HTTPS-туннель должен вести на `http://127.0.0.1:8081`. Если туннель уже работает, используйте его адрес. Для нового временного адреса запустите `cloudflared` в отдельном терминале. [Документация Cloudflare](https://developers.cloudflare.com/tunnel/get-started/quick-tunnels/)

```sh
cloudflared tunnel --url http://127.0.0.1:8081
```

Укажите имя хоста из выданного HTTPS-адреса, без `https://`. Главная страница должна вернуть `200`, запрос API без `initData` — `401` с `Cache-Control: no-store`.

```sh
export ANALYTICS_SITE_ADDRESS=analytics-test.example.com
curl -fsS -o /dev/null "https://$ANALYTICS_SITE_ADDRESS/"
curl -sS -D - -o /dev/null \
  "https://$ANALYTICS_SITE_ADDRESS/api/analytics/overview?period=current-month"
```

## Кнопка «Аналитика»

Настройте кнопку при первом запуске или смене адреса. Укажите `TEST_TELEGRAM_BOT_USERNAME` и токен выделенного тестового бота. Скрипт сверяет имя через `getMe`, сохраняет прежнее меню и меняет кнопку по умолчанию. [Telegram Bot API](https://core.telegram.org/bots/api#setchatmenubutton)

```sh
menu_backup="$(mktemp -d)/menu.json"
node integration/telegram-mini-app/telegram-menu.mjs set \
  "$menu_backup" "https://$ANALYTICS_SITE_ADDRESS/"
```

Для отката восстановите кнопку из того же снимка, затем остановите тестовый прокси. Записи в тестовой базе при этом сохраняются.

```sh
node integration/telegram-mini-app/telegram-menu.mjs restore "$menu_backup"
```

## Проверка в Telegram на iOS и Android

1. Откройте личный чат тестового бота и отправьте `/start` с обоих аккаунтов. На аккаунте A за один календарный день запишите `+7250,50 подработка` и `380,25 кофе`. На аккаунте B за тот же день запишите `91,40 такси`.
2. Сверьте день и суммы с «Историей» бота. Через кнопку «Аналитика» откройте «Этот месяц». Для A в чистом периоде ожидаются `7 250,50 ₽` дохода, `380,25 ₽` расхода и `+6 870,25 ₽` разницы. На графике выберите день записи. Категория «Кафе» должна показывать `380,25 ₽` и `100%`. Для B ожидается только `91,40 ₽` расходов в категории «Транспорт».
3. Проверьте светлую и тёмную темы Telegram, безопасные отступы, прокрутку и выбор дня касанием. Проверьте, сохраняется ли выбранный день, когда открытую аналитику возвращают на экран после смены темы.
4. Сверните Mini App на аккаунте A, удалите расход через сообщение бота и вернитесь в Mini App. Проверьте нулевой расход в итогах и за день, новый итог `+7 250,50 ₽` и отсутствие «Кафе» в списке. У B должны сохраниться его расход и «Транспорт».
5. Зафиксируйте для каждой платформы версию Telegram, тему, суммы, категорию, результат обновления после удаления и проверку второго аккаунта.
